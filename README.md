# Protokollok – Andrew Huberman: *Protocols*, magyarul

Andrew D. Huberman *Protocols* című könyvének magyar fordítása e-könyvként és nyomtatható PDF-ként.

> Nem hivatalos, személyes használatra készült fordítás. Használjátok egészséggel, de vegyétek meg az eredeti könyvet mindenképp!

## Letöltés

| | Mire jó | Letöltés |
|---|---|---|
| 📱 **EPUB** | E-könyv-olvasóra (Kindle, Kobo, Apple Könyvek), telefonra | [protokollok.epub](https://github.com/gergolencses-lab/protocols-translate-hun/raw/main/1-kesz-konyv/protokollok.epub) |
| 🖨️ **PDF (A5)** | Nyomtatásra, vagy számítógépen olvasásra | [protokollok-A5.pdf](https://github.com/gergolencses-lab/protocols-translate-hun/raw/main/1-kesz-konyv/protokollok-A5.pdf) |
| 🖼️ Borító | Külön képként | [borito.jpg](1-kesz-konyv/borito.jpg) |

## Mi hol van

A mappák abban a sorrendben jönnek, ahogy szükség lehet rájuk.

```
1-kesz-konyv/     ← A KÉSZ KÖNYV: EPUB, PDF, borító
2-szoveg/         ← a könyv szövege
   magyar/protokollok.md    ← a magyar fordítás (itt kell javítani)
   angol/                   ← az angol eredeti (PDF és Markdown)
   kepek/                   ← a könyv 4 képe
3-kinezet/        ← hogyan néz ki: borító, az EPUB és a PDF stílusa, betűtípusok
4-dokumentacio/   ← miért ilyen: tervek és döntések
eszkozok/         ← építés és ellenőrzés (ide csak újraépítéskor kell benézni)
```

## Mit hol keress

| Ha… | Nézd meg |
|---|---|
| csak olvasni szeretnéd | [`1-kesz-konyv/`](1-kesz-konyv/) |
| hibát találtál a fordításban | [`2-szoveg/magyar/protokollok.md`](2-szoveg/magyar/protokollok.md) – javítás után újra kell építeni |
| összevetnéd az angollal | [`2-szoveg/angol/`](2-szoveg/angol/) |
| a borítón vagy a betűkön változtatnál | [`3-kinezet/`](3-kinezet/) |
| tudni szeretnéd, miért döntöttünk így | [`4-dokumentacio/`](4-dokumentacio/) |
| újra kell építeni a könyvet | [`eszkozok/`](eszkozok/) – egy parancs: `bash eszkozok/mindent-epit.sh` |
