# Hogyan néz ki

| Mappa | Mi van benne |
|---|---|
| [`borito/`](borito/) | A borító forrása (`cover.html`), a belőle készült kép (`cover.jpg`) és a Montserrat betűtípus. Ugyanezt a borítót használja az EPUB és a PDF is. |
| [`epub/`](epub/) | Az e-könyv stílusa (`epub.css`) és adatai (`metadata.yaml`: cím, szerző, nyelv, jogi megjegyzés). |
| [`pdf/`](pdf/) | A nyomtatható PDF stílusa (`print.css`: A5, margók, élőfej, tördelés) és a betűtípusai (Source Serif 4, Source Sans 3). |

Minden betűtípus szabadon használható (SIL Open Font License), a licencük mellettük van.

Ha itt változtatsz valamit, újra kell építeni a könyvet ([`eszkozok/`](../eszkozok/)). Hogy miért lett minden így, azt a [`4-dokumentacio/`](../4-dokumentacio/) írja le.
